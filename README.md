# 🗓️ Task Reminder App (with Jalali Calendar)

A **Task Reminder / To-Do App** with full support for the **Jalali (Persian) calendar**.  
This app helps you organize your daily, weekly, monthly, and yearly tasks with flexible scheduling options and automatic reminders.  

## ✨ Features
- 📅 **Jalali (Persian) Calendar** support  
- 🕒 Create reminders for:
  - Daily tasks  
  - Weekly tasks (choose specific weekdays)  
  - Monthly tasks (choose specific dates)  
  - Yearly tasks (birthdays, anniversaries, etc.)  
- 🔔 Notifications and alerts for upcoming tasks  
- 📝 Add, edit, and delete tasks easily  
- ☁️ **Backup & Restore** your tasks to keep your data safe  
- 🎨 Clean and user-friendly interface 


# 🗓️ اپلیکیشن یادآور کارها (با تاریخ شمسی)

این اپلیکیشن یک **یادآور کارها (To-Do List)** است که بر پایه تاریخ **شمسی (هجری شمسی)** ساخته شده.  
با استفاده از آن می‌توانید کارهای روزانه خود را مدیریت کنید و برای آن‌ها تاریخ و زمان مشخص تعیین کنید.  

## ✨ ویژگی‌ها
- 📅 پشتیبانی از **تقویم شمسی (هجری شمسی)**  
- 🕒 امکان ایجاد یادآوری برای:
  - کارهای روزانه  
  - کارهای هفتگی (با انتخاب روزهای خاص هفته)  
  - کارهای ماهانه (با انتخاب روزهای خاص ماه)  
  - کارهای سالانه (مثل تولد، سالگرد و غیره)  
- 🔔 اعلان‌ها و هشدارها برای یادآوری کارهای آینده  
- 📝 امکان افزودن، ویرایش و حذف آسان کارها  
- ☁️ **پشتیبان‌گیری و بازیابی** اطلاعات برای حفظ امنیت داده‌ها  
- 🎨 رابط کاربری ساده و کاربرپسند
